# Helloworld rust binding

Helloworld rust binding is a minimal AFB Binding V4 sample implemented in Rust with [`afbv4`](https://github.com/redpesk-common/afb-librust). It exposes the same public `helloworld` API as the C and Python samples while demonstrating how to implement a loadable AFB binding as a Rust `cdylib`.

Checkout the documentation from the [`docs`](docs/) folder or the [redpesk documentation](https://docs.redpesk.bzh/).
